# Official MSU Logo Placement

You can add the official Mindanao State University - General Santos logo file directly to this repository on GitHub!

### How to Add Your Logo:
1. Place your official logo file inside the `/public` folder in GitHub.
2. Name the file one of the following:
   - `msu-logo.png` *(Recommended - high resolution PNG with transparent background)*
   - `msu-logo.svg` *(Vector SVG format)*
   - `logo.png`

### Where it appears automatically:
- Welcome & Portal Landing Page
- Faculty & Student Login Screen
- Password Reset Views
- Official Purchase Request Header & Preview
