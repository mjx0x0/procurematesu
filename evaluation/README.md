# Gab AI RAGAS dataset collection

This evaluation-only utility does not modify the Gab AI chat route, prompts, retrieval ranking, database schema, or knowledge-base records.

## What it collects

For every user_input in the starter CSV, the script calls the same read-only retrieveDocumentChunks(question, 6) function used by Gab AI and writes:

- retrieved_contexts: JSON-encoded array of actual retrieved chunk texts.
- retrieved_sources: JSON-encoded source metadata for traceability.
- retrieval_status and retrieval_error: collection diagnostics.

Existing response, reference, and reference_contexts columns are preserved and are never generated by this script. Complete them using actual chatbot answers and independently verified official source material before RAGAS evaluation. expected_behavior is guidance, not ground truth.

## Prerequisites

- Bun and installed project dependencies (bun install).
- A local .env.local with the Supabase environment variables used by the project. Prefer a read-only Supabase key. Never commit service-role credentials.
- The starter CSV is included at `evaluation/datasets/gab_ai_ragas_starter_dataset.csv` in this branch. You do not need to download or copy it separately.

## Run

From the repository root:

```bash
bun run scripts/collect-ragas-dataset.ts
```

Optional examples:

```bash
bun run scripts/collect-ragas-dataset.ts --input ./path/to/starter.csv --output ./evaluation/datasets/collected.csv
bun run scripts/collect-ragas-dataset.ts --limit 5
bun run scripts/collect-ragas-dataset.ts --delay-ms 300
bun run scripts/collect-ragas-dataset.ts --force
```

Default output: evaluation/datasets/gab_ai_ragas_collected.csv. Existing output is protected from accidental overwrite; use --force only when replacement is intended.

## After collection

1. Inspect retrieval_status for every row.
2. Run each prompt through Gab AI in the normal application and paste its actual answer into response.
3. Independently verify reference and reference_contexts against official procurement sources.
4. Keep rows with no relevant context; review them as retrieval-failure and abstention cases.
5. Parse retrieved_contexts and reference_contexts JSON values as arrays when preparing the RAGAS dataset.

## Safety and scope

- Reads through the existing document_chunks retrieval path only.
- Does not write to Supabase or change knowledge-base content.
- Does not call the chatbot endpoint or generate answers, so it cannot create chat sessions, inquiry logs, PR drafts, or other user-facing side effects.
- Do not add personal, confidential, or live PR information to this evaluation dataset.
